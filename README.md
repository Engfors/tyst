# Tyst

Local, privacy-first meeting transcription and dictation for macOS and Linux. Swedish and English,
including mixed-language meetings. Nothing leaves the device.

Status: **Phase 0** (model evaluation). See [SPEC.md](SPEC.md) for the full specification,
[eval/](eval/) for the evaluation harness and [docs/phase0-report.md](docs/phase0-report.md) for findings.
